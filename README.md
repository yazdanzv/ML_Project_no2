# ML_Project_no2

## Code guide

`car_price_predictor.ipynb` cleans and encodes car data, fits and evaluates regression models, and uses the included car CSV files. `gradient-descent.ipynb` is a separate gradient-descent exercise; `gd.py` provides its cost, gradient, and closed-form helper functions. Open either notebook from the repository root and run cells in order. `requirements.txt` lists dependencies. Keep the two car CSV filenames distinct because both are present in the repository.
